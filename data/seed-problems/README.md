# Seeded HVAC Problems

45 observed problems collected from public sources (primarily Reddit r/HVAC, r/hvacpeople, r/hvacadvice, and industry analyses 2023–2026).

These are **real complaints**, not survey responses. Each file includes source notes, vertical, workflow stage, and representative quotes where available.

Use these to seed the board and test the core validation loop:
- I Have This Problem Too
- I'd Test This
- I'd Pay for This

Priority vertical for first validation: **HVAC**.
