# Auth & Onboarding (MVP)

## Authentication

- Email + magic link (preferred) or password
- Optional Google / Apple later
- No phone requirement in MVP

## Signup Flow (keep it short)

1. Email → magic link
2. Choose display name
3. Select one or more roles (checkboxes):
   - I run / own a business
   - I propose solutions / have domain expertise
   - I build products or tools
   - Just browsing / following
4. If "I run / own a business" is checked → optional business fields (name, vertical, size)
5. Land on home / problem list (seeded content already visible)

No forced profile completion. Users can go deeper later.

## Credibility Signals Shown Publicly

- Role badges next to name (Owner / Solver / Builder)
- Optional business name (if provided)
- Validation weight is higher when the action comes from a Business Owner account

## Anti-Spam / Trust (lightweight)

- Rate limits on posting and validating
- Flagging system for obvious spam
- Manual review of high-activity new accounts if needed
- Future: domain-email or LinkedIn verification for "Verified Owner"

## Guest Experience

- Anyone can browse all problems and solutions without an account
- Actions that create data ("I have this too", propose solution, etc.) require signup
