# Research & Seeding

This folder holds observed business complaints and research notes used to seed the board.

## How to add a problem

Prefer primary sources (Reddit threads, forum posts, review excerpts) over paraphrased surveys.

Format for each seed problem:

```markdown
### [Short title]

**Source:** [link or description]
**Vertical:** HVAC / Plumbing / …
**Workflow stage:** Lead response / Scheduling / Parts / …

> Exact or near-exact quote of the complaint

**Notes:** Why this is a strong signal / frequency observed
```

## Priority Verticals for First Seeding

1. HVAC
2. Plumbing
3. Electrical
4. Cleaning / Janitorial
5. Pest Control

Focus on the lead-to-payment workflow first.
