# Soft Outreach Message Templates

## Template A – Reddit / Public post (problem validation)

**Title ideas:**
- HVAC owners: which of these operational problems is actually killing you right now?
- Quick reality check for small HVAC shops (1–10 techs)

**Body:**

Hey owners / operators —

I’ve been collecting real complaints from HVAC shops about the lead → job → payment workflow. A few that keep coming up:

1. Missed calls after hours / during peak (leads gone before you can call back)
2. Techs wasting 20–45 min every morning checking truck parts vs the day’s jobs
3. Estimates that go cold because there’s no consistent follow-up
4. Dispatch/routing that sends techs all over town with no logic
5. Cash-flow swings + customers who stiff on invoices

If you run a shop (or used to), which of these are real problems for you right now?  
Would you actually test a simple tool that fixed one of them?  
Would you pay for it if it clearly worked?

Just trying to separate real pain from “nice to have.” Appreciate any honest replies.

## Template B – Direct / DM / email (softer)

Subject: Quick HVAC ops question (no pitch)

Hi [Name],

I noticed you run an HVAC company. I’ve been mapping the most common operational headaches shops face (missed calls, truck inventory chaos, estimate follow-up, etc.).

Would you mind telling me which of these, if any, actually costs you time or money right now?

- Missed / slow lead response
- Parts availability on the truck
- Scheduling / routing inefficiency
- Collections or cash-flow timing

No product pitch — just trying to understand what’s real. Happy to share what other owners are saying once I have a few dozen responses.

Thanks either way,
[Your name]

## Template C – “I’d test / I’d pay” follow-up

Thanks for confirming that [problem] is real.

If someone built a dead-simple tool that fixed just that one thing (no big software suite), would you be willing to:

a) Test it for a couple of weeks with your team?
b) Pay a modest monthly fee if it clearly saved time or captured more jobs?

Just a yes/no + rough price range is perfect. Trying to see if the willingness-to-pay signal is actually there.
