# Soft Outreach Plan – HVAC Owners

Goal: Test the core signals without building the full product yet.

- “I have this problem too”
- “I’d test a solution”
- “I’d pay for a solution”

## Where to reach HVAC owners (high-signal, low-noise)

1. **Reddit**
   - r/HVAC (trade-focused)
   - r/hvacpeople
   - r/hvacadvice (more mixed)
   - r/smallbusiness (occasional)

2. **Facebook Groups** (search for local + national)
   - HVAC Business Owners
   - HVAC Contractors Network
   - ServiceTitan / Jobber user groups
   - Local state HVAC association groups

3. **Industry forums & associations**
   - ACCA member communities
   - PHCC chapters
   - Manufacturer dealer portals / Facebook groups

4. **Direct / warm**
   - Local HVAC shops you already know
   - Supply-house counter relationships
   - LinkedIn (search “HVAC owner” + city)

## Soft outreach principles

- Lead with a specific observed problem, not “I’m building an app”.
- Ask for confirmation + willingness signals, not a sale.
- Keep it short. Offer to share aggregated results later.
- Never spam the same person twice.
