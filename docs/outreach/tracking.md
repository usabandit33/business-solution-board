# Outreach Tracking (simple)

Keep a private spreadsheet or note with:

| Date | Channel | Problem referenced | # “I have this too” | # “I’d test” | # “I’d pay” | Notes |
|------|---------|--------------------|--------------------|--------------|-------------|-------|
|      |         |                    |                    |              |             |       |

Target: soft outreach to 30–50 HVAC owners/operators over 2–4 weeks.

Success signal for the MVP hypothesis:
- Multiple independent confirmations on the same problems
- At least a handful of clear “I’d test” or “I’d pay” responses
